# Kissan-Portal

A Flask-based web application for farmers to manage labor records and access agricultural information.

##  Features
- User authentication (Login/Register)
- Labor management (CRUD operations)
- Wage calculation system
- Agriculture info & government schemes

##  Tech Stack
- Python (Flask)
- SQLite
- HTML, CSS
